# My Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

**Live website:** https://rohittk18.github.io/my-Portfolio/

## Features

- Responsive layout for mobile, tablet and desktop
- Mobile navigation menu with smooth scrolling
- Dark / light mode (remembers your choice)
- Scroll reveal animations
- Skills, Projects and Education sections
- Contact form with validation and social links
- Downloadable resume

## Technologies

HTML5, CSS3, JavaScript, Font Awesome, Google Fonts

## Run locally

1. Clone the repository
   `git clone https://github.com/rohittk18/my-Portfolio.git`
2. Open `index.html` in your browser
