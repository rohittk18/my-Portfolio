# Rohit Kumar | Portfolio Website

A responsive, accessible personal portfolio built with plain **HTML, CSS and JavaScript** as part of the Codomax Web Development internship.

**Live website:** https://rohittk18.github.io/my-Portfolio/

## Features

- Fully responsive layout (mobile, tablet and desktop)
- Mobile navigation menu with smooth scrolling and active-link highlighting
- Dark / light mode that remembers your choice
- Scroll reveal animations (respects the "reduce motion" setting)
- Sections: Home, About, Skills, Projects, Education and Contact
- Project cards with GitHub and live demo links
- Contact form with validation and social links (GitHub, LinkedIn, Email)
- Downloadable resume
- Keyboard friendly, with a skip link and visible focus styles
- Social sharing preview tags for LinkedIn and WhatsApp

## Run locally

1. Clone the repository
   ```
   git clone https://github.com/rohittk18/my-Portfolio.git
   ```
2. Open the folder in VS Code
3. Open `index.html` in your browser (or use the Live Server extension)

## Deployment

The site is deployed with **GitHub Pages**:

1. Push the code to the `main` branch
2. Go to **Settings > Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save
4. The site goes live at `https://rohittk18.github.io/my-Portfolio/` after a minute or two
